# 田埂退潮之后 · 门 / 地图 / 窗

同一个静态站点，一条体验：推开门，走进永丰四村的田野地图，再推开一扇窗，看「退潮线」的十件装置方案。界面全部是中文。资源都用相对路径，挂在 GitHub Pages 的 `/yongfeng-field-map/` 下也可以直接打开。

## 门

粒子门楼。可以拖动（有惯性和弹性），点击门，粒子散开再聚成地图。按回车或点「跳过」直接进入。地图上点「回到门」，或按 `G` / `退出`（没有面板打开时），可以回到门楼。

## 地图

姜家岙、东安村、横山腰、吴岸村。鼠标扰动丘陵，点击村子看人与事。`＋` / `－` 缩放，方向键平移，`0` 复位。顶部还有项目、时间线、对比、图库。

深链接 `#dongan` `#hengshanyao` `#jiangjiaao` `#wuan`，或地址带 `?nogate`，会跳过门楼，直接进入地图。

## 窗

「退潮线」十件公共艺术装置前期方案，不是另一个网站。地图上点「退潮线」（村子面板里也可以从该村的装置看起；项目介绍里同样有入口）。

- `#/tuichao` 十件作品的转鼓
- `#/tuichao/index` 索引
- `#/tuichao/work/01` … `#/tuichao/work/10` 作品详情

打开作品时，卡片在同一场景里连续变成详情；详情里可以横向拖到下一件。点「回地图」回到刚才的地图，页面不重新加载。浏览器返回会先退出作品，再回到地图。

单独打开 `window/` 目录时，仍使用原来的 `#/`、`#/index`、`#/work/01`。

## 本地预览

在仓库根目录运行：

```
python3 -m http.server 8780
```

浏览器打开 http://127.0.0.1:8780/ 。Windows 上也可以用本目录的 `serve.ps1`。

## 数据

地图内容在 `data.json`，照片在 `assets/photos/<村 id>/`。退潮线的作品文案在 `window/works.js`，图片在 `window/assets/`。不要手改生成文件；方案改完后按 `window/README.md` 重新导入。
