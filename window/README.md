# 退潮线 · 永丰镇四村公共艺术装置前期介绍

这是整站里的「窗」。嵌在田野地图里时，外层地址是 `#/tuichao`、`#/tuichao/index`、`#/tuichao/work/01` … `10`；单独打开本目录时，仍用原来的 `#/`、`#/index`、`#/work/01` … `#/work/10`。

纯静态网站，不需要构建。本地预览：在本目录运行 `python3 -m http.server 8792`，打开 http://127.0.0.1:8792/ 。

网址（单独打开时）：`#/` 转鼓（十件作品）· `#/index` 索引 · `#/work/01` … `#/work/10` 作品详情。

## 内容从哪里来

作品内容全部来自方案文档，**不要手改 `works.js`**，改 md 后重新导入：

```
cd site && node tools/import-proposal.mjs
# 也可以指定路径：node tools/import-proposal.mjs <方案.md> <效果图文件夹> <线稿文件夹>
```

默认读取上一级目录的：

| 来源 | 用途 |
|---|---|
| `十方案_前期介绍_v2.md`（本次导入时修改时间 2026-10-25 16:22:47 新加坡时间） | 标题、十个方案的字段、总览表、首期 |
| `方案图_v2/NN_名字.png`（跳过 `废弃稿/` 和 00 总览） | 效果图 → `assets/works/NN.webp`（1600px，q82） |
| `线稿_v2/NN_名字.png` + `线稿_v2/svg/NN_名字.svg` | 线稿 → `assets/works/NN-line.webp`（2000px，q92，细线在全屏放大时仍清楚）；视图名从 svg 图名栏读，例如「主立面」「南立面 + 平面」 |
| `线稿_v2/00_线稿总览.png` | 索引视图背后的淡色背景 → `assets/works/lines-overview.webp` |

导入脚本依赖 md 的这些结构（改 md 时请保持）：

- `# 标题`（第一行一级标题）
- `## 三、十个方案` 下面每个方案一个 `### 方案 NN｜名字 —— 村 · 地点`
- 每个方案下面是 `- **字段名**：内容` 的列表。v2 的字段是：选址、在地依据、形态与尺寸、材料、村民参与、落地性、艺术性、生图提示词。
  「艺术性」作为面板里的亮点，「生图提示词」不上网站，其余按 md 原顺序显示，空的显示「待补充」。
- `## 四、十方案总览` 的表格（按表头取「单元 × 数量」和造价），以及写着「首期」的那一行（目前是 05、01、06，带「首期」标记）。
- 造价只在 md 给出时显示（表格或「落地性」里的「造价粗估 …」），不推算。

v2 的其它章节（背景、统一主线、五维度对比、生图风格、待核实清单、资料来源）目前没有上网站。

## 哪些文件是生成的，哪些是手写的

- 生成（会被导入脚本覆盖）：`works.js`、`assets/works/*.webp`
- 手写：`site.js`（网站标题、页脚、提示语）、`index.html`、`css/style.css`、`js/*`
- 田野照片：`assets/field/`，对应关系写在 `tools/import-proposal.mjs` 顶部的 `FIELD` 表里（10 号用的是吴岸村卫星图，图注标明「卫星图」）。
  带人像的照片需要本人同意，目前没有用。

## 图片顺序

每件作品的面板：效果图（标「生图示意，非实景」）→ 方案线稿（标「示意」，点开白底全屏，可滚轮 / 双指缩放、拖动、双击放大，Esc 关闭）→ 田野照片。

## 代码结构

- `js/stage.js`：three.js 转鼓、网格地面、鼠标扰动、卡片形变着色器（含线稿 → 效果图的颗粒溶解）
- `js/transition.js`：卡片 ↔ 详情面板的连续形变（GSAP 时间线）
- `js/detail.js`：面板内容；`js/lightbox.js`：线稿全屏查看
- `js/typecards.js`：卡片贴图排字；`js/main.js`：载入、路由、索引、光标
- three.js 0.170.0 与 GSAP 3.12.5 放在 `vendor/`，不依赖外网；字体来自 Google Fonts，断网时退回系统宋体 / 黑体。
- 系统开启「减少动态效果」时，扰动和形变动画会关掉或变成瞬时切换。

## 详情里左右切换作品（js/strip.js）

- 打开一件作品后，左右屏幕边上露出相邻作品的纸。鼠标横向拖、触摸横滑、触控板横向滚动，或按 ←/→，都能切到相邻作品（10 之后接回 01）。
- 拖动时，离开中间的纸压暗约 50%，内容不动；进来的纸先是一张灰色空纸，到中间时变白，左侧文字、右侧图片依次淡入上移。松手按速度吸附到最近一张（约 0.7 s ease-out）。
- 横向位移比竖向多 8px 以上才算拖动，所以竖向滚动和点线稿放大都不受影响。
- 吸附后用 replaceState 改地址，不新增历史记录，所以浏览器返回仍是关闭。背后的转鼓同步转到这件作品，关闭（× / Esc）时就形变回这件作品的卡片。
- 原生滚动条全部隐藏（Windows 上原生滚动条常显且占宽，形变时会露出来），改成细指示条，面板交接完成后才淡入。
